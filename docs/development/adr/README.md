# Architecture decision records

One file per decision, named `ADR-NNN-title.md` (for example `ADR-001-use-uv.md`). Numbers are sequential:
continue the existing sequence. ADRs are never deleted; a reversed decision gets a new ADR that supersedes
the old one.

Each ADR records the context, the decision, the alternatives considered and why they lost, and the
consequences. The `.adr-dir` file at the repo root points ADR tools here.
